    Michael: 
The receptionist module efficiently manages orders by communicating with the database for 
various functions: viewing customer orders entails retrieving detailed information based on 
order IDs; creating rental orders involves inserting entries into the orders table with default 
'rented' status; listing available clothing items swiftly selects those with 'available' status from 
the items table; and processing returns updates order statuses to 'return' upon item return, with 
additional updates for items requiring cleaning or repair. Implemented in object-oriented PHP, 
the Receptionist class encapsulates these functionalities through methods such as viewOrder, 
createRentalOrder, AvailableClothes, and Rental, each executing prepared SQL queries 
securely and efficiently. This streamlined approach ensures smooth customer interactions and 
optimal inventory control within the vintage clothing store system.
